**关键教训（沉淀）**：
- **summary 必须放 `meta={"summary": ...}`**（不是 `RawItem.summary` 字段）——主流程只读 meta，字段放错摘要静默丢失
- **merge_history 不更新已存在条目的 summary**——修复后需手动回填存量（fetch 重抓按 url 匹配）
- **PDF 提取用 MinerU 不用 PyMuPDF**：PyMuPDF 对图片型/公式密集 PDF 提取失败（World models 2443字），MinerU 完整提取（106584字）；MinerU pipeline 依赖 torchvision 需与 torch 版本匹配（cu121 vs cu128 报 nms 不存在）
- **arxiv 分栏判断用块 x 中心聚类**（不是块边界）——单栏论文窄块落中间带会误判双栏
- **中国站源必须禁用代理直连**：生产 service 经 EnvironmentFile 加载 `HTTP_PROXY=mihomo 夏威夷家宽`，qjem.cn 等中国站走夏威夷出口访问失败致整源 item_count=0 漏抓（本地直连正常，故本地测不出）。修复：`fetch_qjem` 单次请求 `proxies={"http": None}` + 3 次重试。**教训：接中国站源先确认服务器代理环境下的可达性**
