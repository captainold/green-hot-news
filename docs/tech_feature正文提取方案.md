# tech_feature 正文提取方案（审查稿）

> 日期：2026-08-24 ｜ 状态：⏳ 待老温核定提示词后实施
> 关联待办：todo.md「多维标签回填：tech_feature 5.5% 空置 → LLM 批量补」

## 一、核实结论

tech_feature 空置 666 条（Layer2/3）的根因不是"新闻没技术特征"，而是**提取时输入不足**：

| 事实 | 数据 |
|------|------|
| Layer2/3 空置条目里 summary 为空/极短（<30字） | 430 条（65%） |
| 可回填候选（Layer2/3 + tf空 + qmd 有正文） | **656 条** |
| 提取函数当前输入 | 仅 `title` + `summary`（截断 500 字），**无正文** |

典型漏提案例（`Introducing The ForestBench Project`）：
- 正文含"地面测量 + 无人机航拍双路数据采集"技术细节
- 但提取时只有导语 summary（无技术细节）→ 判"无"

## 二、提示词改稿（待核定）

### 当前（tech_feature.py PROMPT_TEMPLATE）

```
你是绿色低碳科技领域的技术情报分析师。从下面新闻的标题和摘要中，提取该新闻涉及的"技术特征"——即具体的技术参数、技术路线、工艺方法或性能指标。

技术特征包括（但不限于）：
1. 降本曲线（成本下降，如"度电成本下降40%"）
2. 设备参数（功率/效率/容量/寿命，如"转换效率26.1%"）
3. 工艺包特点（技术路线/流程，如"闪速焦耳热热化学转化"）
4. 指标要求（政策/规划/项目中的具体技术指标，如"SAF掺混比例1%/2%/5%""绿电占比80%""储能时长4h"）
5. 性能提升（速度/精度/容量提升，如"启动速度提升3倍"）

规则：
- 只输出一句技术特征描述，不超过 50 字
- 新闻完全不涉及任何技术参数/指标/路线时，才输出「无」
- 直接给结论，不要解释、不要前缀

标题：{title}
摘要：{summary}

技术特征：
```

### 改稿（新增正文输入）

```
你是绿色低碳科技领域的技术情报分析师。从下面新闻的标题、摘要和正文中，提取该新闻涉及的"技术特征"——即具体的技术参数、技术路线、工艺方法或性能指标。

技术特征包括（但不限于）：
1. 降本曲线（成本下降，如"度电成本下降40%"）
2. 设备参数（功率/效率/容量/寿命，如"转换效率26.1%"）
3. 工艺包特点（技术路线/流程，如"闪速焦耳热热化学转化"）
4. 指标要求（政策/规划/项目中的具体技术指标，如"SAF掺混比例1%/2%/5%""绿电占比80%""储能时长4h"）
5. 性能提升（速度/精度/容量提升，如"启动速度提升3倍"）

规则：
- 只输出一句技术特征描述，不超过 50 字
- 新闻完全不涉及任何技术参数/指标/路线时，才输出「无」
- 优先从正文提取（正文含完整技术细节）；正文缺失或空时才用标题+摘要
- 直接给结论，不要解释、不要前缀

标题：{title}
摘要：{summary}
正文：{content}

技术特征：
```

**改动点**：① "标题和摘要" → "标题、摘要和正文"；② 新增 `正文：{content}` 输入；③ 规则加"优先从正文提取"。

## 三、实施步骤

1. **改 `extract_tech_feature` 签名**：`extract_tech_feature(title, summary, content="")`，`content` 截断 2000 字（技术参数通常在正文前段，2000 字足够，也控制 token）。
2. **回填脚本 `scripts/backfill_tech_feature.py`**：
   - 遍历 `Notes/数据库/*.qmd`，解析 frontmatter，找 `layer ∈ {Layer2, Layer3}` 且 `tech_feature ∈ {空, "无"}` 的条目
   - 从 qmd 提取 `## 正文` 节（trafilatura 富文本），去 markdown 符号后取前 2000 字
   - 调 `extract_tech_feature(title, summary, content)` 重新提取
   - 提取到特征（非"无"）→ 回填 qmd frontmatter `tech_feature` 字段 + 同步 `data/*.json` + 写 `tech-feature-index.json` 缓存
   - 幂等 + 缓存（同 url 已提取跳过）+ 并发 4（QPS 控制）+ 断点续跑（定期落盘）
3. **回填范围**：656 条候选（Layer2/3 + tf空 + 有正文）。预期其中约 100-150 条能提取到真实特征（其余正文也无技术参数，仍判"无"）。
