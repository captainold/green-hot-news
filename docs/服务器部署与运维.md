## WSL 操作服务器（2026-08-14 沉淀）

**核心事实**：
1. `moltbot260130.pem` 是 Windows OpenSSH 专属密钥，**WSL 的 ssh/scp 连不上**（Permission denied）
2. `sg-moltbot` 别名只在 Windows 的 `~/.ssh/config`，WSL 里没有
3. `/opt/green-hot-news` **不是 git 仓库**——代码同步靠 **scp 推送**，不拉 GitHub
4. 本机 DNS fake-ip 劫持：一律用 IP `47.82.211.111`，不用域名 ywm.life

**模板 1：Notes 仓库 git 操作**（pull/push 到服务器）

```bash
cmd.exe /c "set GIT_SSH_COMMAND=C:/Windows/System32/OpenSSH/ssh.exe -i C:/Users/wenyu/.ssh/moltbot260130.pem -o IdentitiesOnly=yes && cd /d C:\Users\wenyu\Documents\Obsidian_wen\green-hot-news\Notes && git pull --rebase origin master"
```

**模板 2：单条简单远程命令**

```bash
cmd.exe /c "C:/Windows/System32/OpenSSH/ssh.exe -i C:/Users/wenyu/.ssh/moltbot260130.pem -o IdentitiesOnly=yes root@47.82.211.111 'journalctl -u green-policy.service --no-pager -n 30'"
```

**模板 3：复杂命令 / scp 传文件 → 写 .bat 到项目根目录再执行**

```bat
@echo off
set KEY=C:/Users/wenyu/.ssh/moltbot260130.pem
set SSH=C:/Windows/System32/OpenSSH/ssh.exe
set SCP=C:/Windows/System32/OpenSSH/scp.exe
set REMOTE=root@47.82.211.111
"%SSH%" -i %KEY% -o IdentitiesOnly=yes %REMOTE% "cd /opt/green-hot-news && .venv/bin/python -c \"import ast; ast.parse(open('scripts/update_news.py').read()); print('syntax OK')\""
"%SCP%" -i %KEY% -o IdentitiesOnly=yes C:\Users\wenyu\Documents\Obsidian_wen\green-hot-news\scripts\update_news.py %REMOTE%:/opt/green-hot-news/scripts/update_news.py
"%SSH%" -i %KEY% -o IdentitiesOnly=yes %REMOTE% "md5sum /opt/green-hot-news/scripts/update_news.py"
```

**代码同步流程**：本地改脚本 → scp 上传 → 服务器语法检查 → 测试运行（`--output-dir /tmp/gpn-test` 不碰生产）→ systemd timer 每 30 分钟自动用新脚本跑（无需重启）。

**踩坑速查**：WSL ssh 直连 ✗（密钥不认）| `/c/...` 路径 ✗（git sh 不认）| cmd 单行塞复杂命令 ✗（引号嵌套炸）| 服务器 `git pull` ✗（非 git 仓库）| `ssh sg-moltbot`（WSL）✗（别名在 Windows）| 域名 ✗（fake-ip 劫持）。

## 本地 ↔ 服务器同步（Obsidian Git 插件）

### 通道配置

- **本地仓库**: `C:\Users\wenyu\Documents\Obsidian_wen\green-hot-news\Notes\`
- **origin**: `sg-moltbot:/srv/git/green-policy-materials.git`
- **Windows SSH 配置**: `C:\Users\wenyu\.ssh\config` 中别名 `sg-moltbot`
- **密钥**: `C:\Users\wenyu\.ssh\moltbot260130.pem`

### 插件配置（`.obsidian/plugins/obsidian-git/data.json`）

```json
{
  "basePath": "Notes",
  "autoSaveInterval": 15,
  "autoPullInterval": 15,
  "autoPushInterval": 30
}
```

- 服务器 → 本地：插件每15分钟 pull（服务器每30分钟抓取提交）
- 本地 → 服务器：插件每30分钟 push（Obsidian 内编辑 wiki/笔记）

### ⚠️ 注意事项

1. **本地 DNS 有代理劫持**：`ywm.life` 会被解析成 198.18.x（fake-ip），SSH/git 必须用别名 `sg-moltbot` 或 IP，不能用域名
2. **密钥权限**：Windows 侧密钥需仅当前用户可读（OpenSSH 要求），用 PowerShell 设置 ACL
3. **obsidian-git 改 basePath 后需重启 Obsidian 生效**
