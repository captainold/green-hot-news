## 部署架构

```
新加坡服务器 47.82.211.111
├── systemd timer: green-policy.timer（每30分钟）
│     └→ green-policy.service
│           └→ /opt/green-hot-news/green-policy-sync.sh
│                 ├─ 1. update_news.py 抓取 15 个源
│                 │     ├─ 官方部委/国际组织 → Notes/政策库/
│                 │     ├─ 媒体/热榜 → Notes/媒体库/（关键词过滤）
│                 │     └─ 生成 data/*.json 网站数据
│                 ├─ 2. Notes/ git commit + push → /srv/git/green-policy-materials.git
│                 └─ 3. data/ 站点数据更新
└── nginx: https://ywm.life → /opt/green-hot-news（静态站点直出）
```

## 常用运维命令

## 本地 ↔ 服务器同步（Obsidian Git 插件）

### 通道配置

- **本地仓库**: `C:\Users\wenyu\Documents\Obsidian_wen\green-hot-news\Notes\`
- **origin**: `sg-moltbot:/srv/git/green-policy-materials.git`
- **Windows SSH 配置**: `C:\Users\wenyu\.ssh\config` 中别名 `sg-moltbot`
- **密钥**: `C:\Users\wenyu\.ssh\moltbot260130.pem`

### 插件配置（`.obsidian/plugins/obsidian-git/data.json`）

```json
{
  "basePath": "Notes",
  "autoSaveInterval": 15,
  "autoPullInterval": 15,
  "autoPushInterval": 30
}
```

- 服务器 → 本地：插件每15分钟 pull（服务器每30分钟抓取提交）
- 本地 → 服务器：插件每30分钟 push（Obsidian 内编辑 wiki/笔记）

### ⚠️ 注意事项

1. **本地 DNS 有代理劫持**：`ywm.life` 会被解析成 198.18.x（fake-ip），SSH/git 必须用别名 `sg-moltbot` 或 IP，不能用域名
2. **密钥权限**：Windows 侧密钥需仅当前用户可读（OpenSSH 要求），用 PowerShell 设置 ACL
3. **obsidian-git 改 basePath 后需重启 Obsidian 生效**
