## 这是什么？

[绿色低碳创新动态雷达](https://ywm.life) —— 聚合国内外绿色低碳动态的情报雷达：

- **三层覆盖**：政策（为什么）→ 创新（可能吗）→ 产业（成了吗）
- **74 个信息源**：部委官方、国际组织、学术期刊、产业媒体、全球热点
- **六维打分**：内容强度 / 来源权威 / 主题相关 / 人物 / 时效 / 技术成熟度 TRL（[评分标准公开版](评分标准-公开版.md)）
- **每日更新**：每 30 分钟抓取一轮，首页实时时间线

## 怎么反馈？

| 类型 | 操作 |
|------|------|
| 🐛 报告问题 | 建 Issue，选 `bug` 标签（页面异常/翻译问题/数据缺失） |
| 📰 新闻线索 | 建 Issue，选 `新闻线索` 标签（发现值得收录的源或动态） |
| ⚖️ 评分异议 | 建 Issue，选 `评分异议` 标签（附新闻标题 + 链接 + 理由） |
| 💡 建议 | 建 Issue，选 `建议` 标签，或到 Discussions 发帖 |
| ✉️ 邮件 | feedback@ywm.life（正式反馈，7 天内答复） |
