### 1.4 其他关键发现

- **重复条目**：重复 URL **116 组 / 242 条（占全库 19.6%）**；重复标题 76 组 / 160 条。export_qmd 的 `existing_urls` 精确匹配去重**未生效**——Google News 动态 URL（`CBM…` token 每次不同）、历史文件 url 字段缺失是主因。
- **增长形态**：1235 条中 1174 条（95%）是 2026-08 全量导入，日常增量每 30 分钟仅几条~几十条；attachments 328 文件共 94.4MB。
- **检索层现状**：`analysis/` 有 `四维透视.ipynb` 离线分析，但 **Notes 内无 Dataview 查询模板、无索引文件**，Obsidian 侧多维检索完全没落地。

## 三、最重要的 3 个改进方向

1. **去重治理（S1，P0）**——19.6% 的条目重复，污染所有统计、检索与图谱，是数据地基问题，必须先修。
2. **多维标签回填（R1 + W3 + F1 的组合，P0）**——tech_feature 仅 5.5% 有值、enabling_tech 空 66.5%、eu_taxonomy 空 63.8%，而"四维标签"正是老温顶层设计的全部价值所在；配合 Dataview 模板让标签立即可检索，形成"标签→检索→补标签"闭环。
3. **图片本地化攻坚（F3 + C3，P1）**——48.7% 的图片仍是外链，随时可能 404，Obsidian 本地库的"本地化"承诺就打了对折；中国能源报单站占外链 53%，按站点策略修复性价比极高。

## 附：统计口径说明

- 无正文：正文不含 `## 正文` 节（与 export_qmd 幂等判断一致）。
- 图片外链：`![...](http(s)://...)` 引用；本地化 = `attachments/` 相对引用。
- 字段缺失：空字符串 / 空列表 / `"无"` 占位 均计为缺失；"合理空"指该字段按设计对部分 Layer 不适用（如 Layer1 政策类无 trl/ipc/tech_feature）。
- 全量扫描 1235 个 qmd，无抽样误差；统计脚本保留在 `scripts/tmp_stats_qmd*.py` 可复跑。
