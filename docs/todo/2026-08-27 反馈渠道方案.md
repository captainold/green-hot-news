## 一、渠道设计总览

```
网站用户（ywm.life）
   │  「📮 反馈」按钮 + 「🎯 评分标准」页
   ├─→ 微信扫码进群（国内最快，老温运营）──→ 群公告引导正式意见走邮箱/Issues
   ├─→ 邮箱 feedback@ywm.life（正式/长文）──→ AI cron 每周汇总 → 00-待办总清单
   └─→ GitHub Issues（开发者/海外）──────→ 同上汇总
          GitHub Discussions = 论坛雏形（长期愿景第一步）
```

原则：**渠道分流不重复**——每类人流向最顺的出口；意见最终都沉淀进 00-待办总清单（单一事实源）。
