# 知识图谱实体与双链规范（Entity & Link Spec）

> 版本: v0.1 草案 | 更新: 2026-09-14
> 状态: **v0.1 已确认（2026-09-14 老温定稿）**，待进 P1
> 权威关系: 本文档补充 `本体与标签词典.md` 未覆盖的「实体层 + tags 命名空间 + 双链 + 三库合并迁移」规范。
> 与 `本体与标签词典.md` 的分工：本体词典管「一条信息有什么属性（多维标签）」，本文档管「信息之间如何连成图谱（实体节点 + 边 + 目录结构）」。

## 一、背景与目标

现状（2026-09-14 实测）：

- Notes 三库并存且高冗余：政策库 3346 md / 媒体库 6211 md / 数据库 7022 qmd，去重后约 10653 条，约 5900 条重复存储。
- 政策库/媒体库是「按来源分目录的简易素材层」（7 字段），数据库是「平铺 + 21 字段多维标签的全量打标层」。
- 缺实体层：机构/技术/人物/主题仅以文件夹或扁平 tag 存在，图谱视图无「节点」。
- 双链三套并存且脆弱：qmd 的 `related` 存文件名、wiki 用相对路径、索引页用文件夹链接。

目标（老温 2026-09-14 定稿方向）：

1. 建独立 `Notes/实体/` 目录承载图谱节点。
2. 政策 wiki 深化到政策条目级（12 板块深化 + 重要政策建条目实体页）。
3. frontmatter 加稳定 `id` 字段，双链统一指向实体，改文件名不断链。
4. **三库（政策库+媒体库+数据库）合并为一个库**，统一格式为 qmd。

## 二、实体层（Entity Layer）

### 2.1 实体类型（6 类，前缀即类型）

| 类型 | 英文 | id 前缀 | 说明 | 存放位置 |
|------|------|---------|------|---------|
| 政策法规 | Policy | `pol` | 重要政策条目（含文号/效力/发布机构/关联政策） | `实体/政策/` |
| 机构组织 | Org | `org` | 部委、国际组织、企业、媒体源 | `实体/机构/` |
| 人物 | Person | `per` | 官员、专家、分析师 | `实体/人物/` |
| 技术 | Tech | `tec` | 光伏、储能、氢能、CCUS、AI 等 | `实体/技术/` |
| 主题概念 | Topic | `top` | 碳市场、新能源、电力改革… | **= 政策wiki 综述页**（不另建目录） |
| 地区 | Region | `reg` | 中国、欧盟、美国、印度、日本、国际 | `实体/地区/` |

> **主题实体页 = 政策wiki 12 板块综述页**：wiki 综述页加 `id` 字段即成为主题实体节点，避免「wiki 综述」与「主题实体」重复维护。

### 2.2 id 规则

- 格式：`<前缀>/<细分>`，全小写、无空格、稳定不变。
- 示例：`pol/cn-ndrc-2025-零碳园区`、`org/cn/国家发改委`、`tec/光伏`、`top/碳市场`、`reg/中国`、`per/黄润秋`。
- 用途：`related` 字段存 id（机器可读、稳定），正文双链用标题（人读、Obsidian 原生解析）。
- **Obsidian alias 机制**：实体页 frontmatter 加 `aliases: [id]`，使 `[[id]]` 与 `[[标题]]` 双向解析，改标题不断链。

### 2.3 实体页 frontmatter 模板（以机构为例）

```yaml
---
id: "org/cn/国家发改委"
type: "org"                 # 实体类型（org/pol/per/tec/top/reg）
name: "国家发展和改革委员会"
aliases: ["国家发改委", "发改委", "NDRC", "org/cn/国家发改委"]
region: "中国"
topics: ["碳市场", "新能源", "电力改革"]
related: []                 # 存其他实体的 id（机器可读）
tags: [type/org, region/中国]
created: 2026-09-14
---
```

## 三、tags 规范（分层命名空间）

废弃现扁平标签（`[中国, 政策文件, 行业动态]` 这类混合体），改用命名空间分层：

| 前缀 | 含义 | 示例 |
|------|------|------|
| `type/` | 内容类型 | `type/policy` `type/news` `type/research` |
| `region/` | 地区 | `region/中国` `region/欧盟` `region/美国` |
| `topic/` | 主题 | `topic/碳市场` `topic/新能源` `topic/储能` |
| `tech/` | 技术 | `tech/光伏` `tech/氢能` `tech/CCUS` |
| `org/` | 机构 | `org/国家发改委` `org/IEA` |

清理规则：

1. `keywords` 字段废弃，其内容若属于标准主题/技术/地区则映射进对应 tag，否则丢弃（实测 keywords 大半是从标题切的英文单词，无检索价值）。
2. 无区分度兜底标签（`行业动态`、`国际`、`中国` 单独出现）清除，由 `type/` + `region/` 承接。
3. 多维标签（dimension/layer/eu_taxonomy/isic/gics/ipc/enabling_tech/topics/region）继续走 frontmatter 字段，**不进 tags**，避免「字段标签」与「导航标签」重复。

## 四、双链规范

| 场景 | 用法 |
|------|------|
| 素材引用实体 | 正文写 `[[实体标题]]`，如 `[[国家发改委]]`、`[[碳市场]]` |
| qmd 机器关联 | frontmatter `related: [id1, id2]` 存实体 id |
| 素材间关联 | `related` 存 id（替代现在存文件名的做法） |
| 图谱边 | 由正文 `[[...]]` 形成，`related` 字段不参与图谱（供脚本/检索用） |

> 关键：**图谱的边靠正文 `[[...]]`，机器的关联靠 frontmatter `related[id]`**，两者分工。改文件名不断链靠 `id` + `aliases`。

## 五、三库合并迁移方案

### 5.1 目标结构

```
Notes/
├── 实体/            # 新建：图谱节点
│   ├── 政策/        # pol-* 重要政策条目
│   ├── 机构/        # org-*
│   ├── 技术/        # tec-*
│   ├── 人物/        # per-*
│   └── 地区/        # reg-*
├── 素材库/          # 三库合并（原 政策库+媒体库+数据库）
│   ├── 政策/        #   政策源，按 国家/机构 分目录
│   └── 媒体/        #   媒体源，按 媒体源 分目录
├── 政策wiki/        # 保留，12 板块综述 = 主题实体页（加 id）
└── （原 政策库/ 媒体库/ 数据库/ 三目录退役）
```

### 5.3 author 回填规则（实测结论）

- 政策库 author 590 条：真司局名（`环资司`）→ 回填；污染（`时间：xxx`、`央视新闻 时间：xxx`）→ 丢弃。
- 媒体库 author 1425 条：RSS 源标注（`The Verge：AI（RSS）· theverge.c`）→ 低价值，丢弃，不回填。
- 清洗规则（P2 实现时细化）：
  1. 含 `时间：`、`（RSS）`、`· xxx.com`、`公众号：` 等污染特征 → 丢弃。
  2. 纯短中文机构名/司局名（`环资司`、`节能司`）→ 回填 `author`。

### 5.4 去重规则（4155 条重复）

- 素材层 md ↔ 数据库 qmd 同 url 重复：**保留 qmd 版**（21 字段完整），素材层那份删除，但先执行 5.3 的 author 回填。
- 去重后总量约 10653 条。

### 5.5 补标签（素材层独有 5134 条）

- 这 5134 条数据库未覆盖，frontmatter 仅 7 字段。
- 复用 `update_news.py` 的 `categorize_dimension()` / `classify_trl()` / `classify_eu_taxonomy()` / `classify_isic()` / `classify_gics()` / `classify_ipc()` / `classify_enabling_tech()` 批量补全多维标签。
- 需新建一个 `scripts/backfill_ontology.py`，输入素材层 md，输出统一 qmd。

### 7.1 主题实体命名统一（进 P1 前必须定）

实测发现 topics 标签名与 wiki 12 板块名**不一致**，主题实体（top）以哪套命名为主，需老温拍板：

|------------|--------------|------|

| 工业绿色转型 | （无对应） | topics 缺 |
| 国际政策 | （无对应） | topics 缺 |
| （无对应） | 储能 / 化石能源 / 节能降碳 / 电动车 / 循环经济 / 政策法规 | wiki 缺 |
