# 信息收集目标地图（绿色低碳动态雷达 · 信源版图 v1.0）

> 定位：本项目（绿色低碳动态雷达）的**信源总清单与接入路线图**，是政策库/媒体库扩容、人工跟踪、报告写作的工作起点。
> 范围：中国、美国、欧盟、日本、印度五大经济体 × 8 类机构（政府/院所/大学/智库/券商/评级数据/综合媒体/特色媒体）+ 国际组织。
> 标记：★ 已在雷达（现有 38 源）｜● P0 建议首批接入｜○ P1 第二批｜△ P2 人工跟踪/备选
> 维护：新增/失效信源在此更新，并在 scripts/update_news.py 中登记 SOURCE_SCORE 与 SITE_LAYOUT。

## 使用说明

- **政策库**（官方原文，权威性最高）：政府官网的政策栏目、官方解读、发布会实录 → 打分体系里 SOURCE_SCORE 最高档。
- **媒体库**（二手转述）：行业媒体、特色媒体、综合媒体能源/气候频道 → 需 `is_policy_relevant` 关键词过滤（碳/能源/气候/环保/ESG/绿色）。
- **智库/研究所**：报告型内容为主（政策类型记"报告15"），多数有 RSS 或 Publications 列表页，适合周度深挖，不做 30 分钟级刷新。
- **券商研究**：公开渠道多为研报摘要/媒体转述，全文在慧博/东方财富/见微等平台 → 建议**人工跟踪 + 关键词监控**（微信/官网研究频道）。
- **数据源**（EIA/Ember/BNEF/Mercom 等）：数据快照型，适合周报/月报引用，不建议进 24h 新闻流。
- 抓取技术路线：RSS/Atom 直抓 → 列表页 HTML 解析 → Google News RSS 兜底（WAF 拦截时）→ 微信公众号/领英人工跟踪。详见 §7。

### 7.2 技术接入路线（每个源按此顺序尝试）

1. **RSS/Atom 直抓**：国际媒体、智库（Carbon Brief、Canary、Agora、E3G、日经等大多有 feed）→ `fetch_rss_feed`。
2. **列表页 HTML 解析**：政府官网（无 RSS 时）→ 参考 ndrc/mee 模式，过滤域名+日期路径。
3. **Google News RSS 兜底**：WAF/Cloudflare 拦截时（北极星、CleanTechnica 已验证的模式）：`news.google.com/rss/search?q=...&hl=...`。
4. **JSON API**：能源局 CMS 模式（`/xwzx/ds_{id}.json`）、EIA API（api.eia.gov）、EEA/Ember 有开放数据接口。
5. **人工/半自动**：券商研报、微信公众号 → 周度人工扫描 + 关键词告警（可后续接 allnet.hot 的站内搜索 API 做关键词监控）。
6. **数据快照型**（EIA/Ember/Mercom/CPIA/CNESA/ISEP）：建议做**周度快照 JSON**（data/snapshots/），供 wiki 知识层引用，不进 24h 新闻流。

### 7.3 维护规则

- 新源接入时在 `scripts/update_news.py` 登记：`SITE_LAYOUT`（库类型/分组）、`SOURCE_REGION`、`SOURCE_SCORE`（v2.0 档位：部委 25/官方解读 23/国际组织 22/专业媒体 18-20/行业媒体 13-16/热榜 8-12）、`GREEN_SITES`（全站绿色才加）、AI 源加 `AI_SITES`、国外官方源加 `FOREIGN_GOV_SITES`（7 天宽窗口）。
- 本文档与 README「覆盖范围」同步更新；失效源（403/404 连续 7 天）降级或移除并记录原因。
- 券商研究、公众号、付费数据等人工层，每季度复核一次清单。
- 区域标签（SOUCE_REGION）：本版图国家按 中国/美国/欧盟/日本/印度/国际 六区，与 auto_tag 的 region 维度对齐。
