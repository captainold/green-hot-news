## 二、为什么是 Excalidraw ＋ Slideshow 脚本

| 方案 | 判断 |
|---|---|
| PPTX / PDF | 投屏稳、能分发；但图与笔记分家 |
| Obsidian Canvas（核心） | 无放映模式，画布上所有节点同时可见（讲稿会被听众一起看到） |
| **Excalidraw ＋ Slideshow 脚本（采用）** | 图与讲稿同源、可现场改字、逐 frame 全屏放映、**讲稿走 presenter notes 窗口，听众看不到** |

Excalidraw 插件本身**没有**放映命令（已核对命令清单）；放映靠官方 **Slideshow 脚本**（`Excalidraw/Scripts/Downloaded/Slideshow.md`）。脚本规矩（读源码确认）：

- 一个 **frame = 一页**；帧名默认按**字母序**排序（本方案另写显式 `order` 元数据锁定）
- 讲稿存 `frame.customData.slideshow.notes` → presenter notes 窗口，投屏画面看不到
- 画幅默认 **1920×1080**；键位 **↓/→/Space** 下页、**↑/←** 上页、Home/End 首末页、**F** 全屏、**Esc** 结束
- 启动：脚本图标**点击**＝全屏；**Alt+点击**＝窗口；**Ctrl+点击**＝放映编辑器

## 三、交付清单

| 文件 | 作用 |
|---|---|
| `演示文稿.excalidraw` | **主交付**：11 页，frame＝幻灯片，每页带讲稿 |
| `讲稿.md` | 讲稿全文（按页编号），可打印／手机看 |
| `预览/01…11-*.png` | 每页渲染图，放映前离线检查；也是"没装 Obsidian"的兜底 |
| `图/01…04.excalidraw` ＋ `图/01…04.png` | 四张源图（可编辑） |
| `生成脚本/` | build_diagrams → render_png → build_deck → preview_pages |

### 生成脚本（幂等）

```bash
cd "docs/Personal Knowledge Management/生成脚本"
python build_diagrams.py   # 画四张源图
python render_png.py       # 源图 → PNG
python build_deck.py       # 源图 → 演示文稿（拆页 + 讲稿写入 frame；保留手改封面）
python preview_pages.py    # 逐页渲染 预览/
```

> **封面手改后保留**：`build_deck.py` 会读现有文件的 `01 封面` frame 及其子元素、原样搬入，其余页重建。改封面在 Excalidraw 里改，重跑脚本不会覆盖封面。

## 四、现场操作（三步）

1. Obsidian 打开 `演示文稿.excalidraw` → 「More options ▾ → Switch to Excalidraw view」（若打开的是 md 视图）
2. 工具栏点 **Slideshow 脚本图标** → 直接全屏放映
3. 讲稿：单屏用「Slides only」＋ 手机/打印 `讲稿.md`；双屏选「With Notes」，讲稿在另一窗口

改顺序/补讲稿：Ctrl+点击脚本图标打开放映编辑器（拖拽排序、按 `N` 编辑讲稿、`Space` 排除某页）。

## 五、风险与注意事项

1. **数据口径**：举例与图里的实测数字取自 `data/history.json`（最后生成 2026-09-03）。**讲之前跑一轮 `update_news.py`** 换当天数字；举例条目若想换更新的，也重新取数。
2. **脱敏已完成**：不出现服务器 IP、SSH 别名、admin 账号、仓库绝对路径。
3. **打分实现细节**：对同事讲六维框架即可，不必展开关键词表。
4. **不夸大**：实体骨架与三库合并已完成（P0-P2），双链迁移与图谱校验仍在推进。
5. **图页是"整图拆页"**：源图改动后需重跑 `build_deck.py` 才同步到幻灯片；反过来在 Excalidraw 里手改幻灯片，重跑会覆盖（封面除外）。
6. **入库提醒**：本文件夹在 green-hot-news 主仓内，Obsidian Git 插件会随笔记自动提交；不想入库就把 `预览/`、`图/*.png` 加进 `.gitignore`。
